# Anonymous submission package

This copy excludes Git metadata, development archives, local caches and credentials. Repository account identifiers, personal paths, email addresses, repository commit references and host names were replaced with anonymous placeholders. Absolute paths under `/opt/anonymous` must be configured for the receiving machine.

Model weights, runtime prompt contents, and saved per-case predictions were not intentionally changed. Sanitized provenance is not a byte-identical copy of the original provenance. Hash lists below describe this distribution, not the original private package. No training, evaluation, or remote publication was performed during packaging.

The included result files and model hashes may still be linkable to previously public artifacts. Text sanitization cannot guarantee unlinkability to a public release.
