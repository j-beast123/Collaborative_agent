# Collaborative Agent final paper package

This directory is the local, self-contained Paper artifact. It contains the
source code, frozen prompts, exact training/evaluation configuration, reported checkpoint LoRA,
data identities, saved predictions, and a read-only evaluator.

The frozen artifact is under `artifacts/reported_checkpoint/`. The repository also
retains supporting implementation and historical material. Do not include API
credentials, private environment files, or model caches in a distribution.

## Pipeline

1. Qwen3-8B Agent and Gemma 3 12B Doctor produce a multi-turn tree rollout.
2. The answer-neutral partner-side reflection identifies one behavioral locus.
3. Gemini 3.8 Flash generates one rubric or reuses a same-behavior rubric.
4. GPT-5.6 Luna performs rubric Gate and response scoring.
5. Score-0/score-2 guided reruns test outcome change.
6. KEEP rubrics provide the rubric-only response reward for GRPO.
7. The reported checkpoint LoRA is evaluated on all 622 held-out cases.

The partner-side reflection is generated by a separate Claude Haiku observer.
It analyzes the Doctor's expressed request and subsequent response; it is not a
hidden answer judge and is not text authored by the local Gemma Doctor model.

## Local verification

```bash
cd /path/to/Collaborative_agent
bash scripts/verify_package.sh
```

The default evaluator invocation is a dry preflight. It does not load a GPU
model or contact the Doctor service until `--launch` is explicitly supplied.

## External requirements for a fresh run

- CUDA-capable PyTorch 2.6.0 and packages in `requirements-eval.txt`
- Hugging Face `Qwen/Qwen3-8B` at the pinned revision
- Ollama 0.12.5 with the pinned `gemma3:12b-it-q8_0` digest
- Private API credentials for the frozen Gemini, Claude, and Luna roles when
  reproducing training

Never add API keys or private `.env` files to this directory.
