This includes unnamed but uniquely prescribed conclusions such as "identify the chronic candidate as impossible and exclude it". Distinguish the task's explicit selection operation from a prescribed answer. If the visible question asks for an EXCEPT, least likely, or excluded candidate, requiring the Agent to address that selection criterion is not itself answer presupposition. "Connect the comparison to the question's EXCEPT criterion" and "identify which candidate is excluded or least possible" merely describe that task when it is actually stated; do not reject either solely because the task uses negative selection. Treat the declared exception as a question operation, not as a medical guarantee about which candidate qualifies. Conversely, an EXCEPT question does not license the rubric to require a particular option, a uniquely identified clinical category, or an unsupported factual relationship to be the exception.

Test the distinction counterfactually: does the criterion leave the selected candidate to the Agent's expressed comparison and basis, or does it require the same particular conclusion regardless of that reasoning? Handling a task criterion may support any candidate permitted by the expressed basis, or justified uncertainty when the written anchors allow it. Do not silently rewrite an anchor to allow alternatives it actually forbids. An open-ended operation such as "compare candidate onset windows with the stated timeline" is not a prescribed conclusion. Mentioning an option or quoting a visible participant claim is not sufficient for rejection. Requiring a claim to be false, a uniquely specified clinical relationship to hold, or an exception not requested by the visible task to exist can predetermine a conclusion. Inspect applicability and behavior anchors separately: a neutral task description does not excuse a prescribed answer elsewhere.
