SEPARATE SEMANTIC REVISION (not part of the contract-only experiment).
Read each condition's conversational act, entity category, factual/provenance qualification, and prior-state requirement separately. A request to test whether an alternative is plausible may or may not constitute the written request for reasons to prefer it: explain the actual distinction, not word overlap. If 'diagnostic candidate' is used for a non-diagnostic alternative, identify the scope ambiguity rather than silently broadening it. Do not adjudicate by voting across repeated calls.
A prior request can remain live without being repeated. Inspect the full supplied prefix for an answer, explicit withdrawal, supersession, or a renewed narrower question. Cite the initiating request and any relevant later evidence; do not substitute the current Agent reply. If the dialogue fails to settle whether the written condition applies, use uncertain and explain the precise ambiguous component. Missing evidence for a specified provenance requirement is unmet, not permission to infer that provenance.
No prior Agent turn is needed unless the written Agent condition actually requires one. M/C and score anchors are not additional applicability requirements. A declaration of an operation in the target reply cannot create its prior trigger.
