

ADDENDUM: RUBRIC FORMAT, USER-SIDE CONTEXT AND AGENT-SIDE STATE

Each rubric has `applicability` (user_side_context, agent_side_state) and
three self-contained levels in `scores` ("0", "1", "2"); every level repeats
the same user_side_context and agent_side_state and states the `behavior`
for that level. A rubric is applicable only when both conditions hold before
the target agent turn:
- user_side_context: check it against what the user/clinician actually did in
  the dialogue before the target turn;
- agent_side_state: check it against `agent_pre_response_state`, the agent's
  own turn-local judgment computed before the response (its position, which
  position it found better supported, and whether it judged the evidence
  sufficient). If the state is `initial_turn_fixed`, the agent side is its
  initial answer only. If the state is null, the agent side cannot be
  confirmed; use applicable=false unless the condition is evident from the
  dialogue itself.

Then compare the response with the three levels' `behavior` and choose the
level that matches; the context is the same for all levels. The
pre-response state is the agent's own assessment, not ground truth.
